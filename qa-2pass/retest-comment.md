# 재시험 결과 댓글 틀

판정하는 사람(설정 C3)이 읽고 통과 · 실패를 정할 근거다. **상태 지시는 쓰지 않는다** — 「통과로 옮겨 주세요」 대신 정상/문제 사실만.
멘션 대상 · 말투 · 요청 머리 형식 · 캡처 필수 여부는 **설정 C4** 를 따른다. 아래는 C4 가 「요청 머리 있음 · 존댓말」일 때의 모양이다.

```text
<요청 머리 — 설정 C4 형식. 예: 📌 요청>
- <C4 멘션 대상>: 아래 확인 결과를 보시고 확인 통과 여부를 판단해 주시기 바랍니다.
  막히는 것: <없음 / 무엇>

<테스트 서버> 확인 결과 (<날짜> · 프론트 <커밋> · 배포 <시각> 확인)
확인 계정 · 화면: <등급(계정)> · <폭> · <언어>

정상
- C1 <기대가 그대로 보였다는 사실 한 문장> (<측정값 · 캡처 열람 서술>).
- X2 <확장 기준도 같았다는 사실> (<진입점 · 폭>).
문제
- C3 <한 줄> — 기대: … / 실제: … / 재현 2/2   <캡처>
확인하지 못한 것
- C5 <이유 — 없는 계정 조합 · 데이터 없음 · 실기기 전용>
범위 밖 (이번 확인과 무관)
- <발견 한 줄>
데이터: <만든 것 없음 / 만들고 지운 것 / 남은 것>
트래커 대체: <없음 / 대체로 돈 동작>
```

## 쓰는 규칙

- **문제가 하나라도 있으면 맨 위 요청 문장에 「문제 N건」을 적는다** — 판정하는 사람이 본문을 다 읽기 전에 안다.
- 정상 줄에도 **무엇으로 확인했는지**를 붙인다. 「정상」 두 글자만 쓰지 않는다.
- 캡처는 설정 C4 가 필수면 문제 줄마다 하나 이상. 업로드는 ⑥ 동작으로, 못 하면 판정서 폴더 경로를 적는다.
- 판정서에만 있는 내용(목업 · 측정 원본)은 댓글에 다 붙이지 않는다 — 판정서 위치를 한 줄로.
- 개인정보 · 내부 주소 등 쓰면 안 되는 정보는 설정 C14.
- 한글 본문을 고쳐 다시 올릴 때는 부분 수정 대신 **전체 본문**으로 쓴다(부분 수정이 한글을 깨뜨린 트래커가 있었다).
