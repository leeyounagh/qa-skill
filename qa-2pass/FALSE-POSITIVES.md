# 오탐 체크리스트

2차에서 **항목마다** 아래를 통과시킨다. 하나라도 걸리면 그 항목은 재측정·재판정 대상이다.
전부 실제 QA 에서 오탐을 만든 적이 있는 유형이다.

## A. 측정 실패 계열

| 증상 형태 | 확인할 것 |
|---|---|
| 「안내·토스트가 없다」 | 클릭 **전에** MutationObserver 를 심었는가. 안 심었으면 재측정 (`PASS1-blind.md` 측정 위생 가) |
| 「눌러도 반응이 없다」 | 안 닫은 얼럿·모달이 클릭을 삼키지 않았는가 — `[role=dialog]` 개수 0 확인 |
| 「값이 안 보인다」 | `readonly` input 인가. `innerText` 대신 `value` 로 읽어봤는가 |
| 「버튼이 없다」 | `aria-label` 만 있는 아이콘 버튼인가 |
| 「B 검증이 없다」 | 순차 검증 화면에서 앞 필드 A 를 채웠는가 |
| 「조회 실패를 삼킨다」 | 실패를 **실제로 주입했는가**. 라우트 패턴이 쿼리스트링을 놓치면 실패가 주입되지 않는다 — `**/path*` 로 잡고 네트워크 5xx 를 눈으로 확인 |

옵저버로도 0건이면 그건 근거가 된다 — **같은 세션에서 옵저버가 다른 토스트를 실제로 포착했음**을
양성 대조군으로 함께 제시한다.

## B. 미배포 계열

테스트 서버에서 재현되는데 **기준 브랜치 코드에는 수정이 있으면 → 결함이 아니라 배포 시차다.**
중복 코퍼스에서 「수정 완료」로 종결된 항목인지 먼저 찾는다.

역방향도 본다 — 테스트 서버가 최근 PR 이전 빌드면, 그 PR 이 고친 것들이 재현되는 게 **정상**이다.
1차 시작 시 빌드 시점을 확인해 두면 이 판정이 쉬워진다.

## C. 권한 계열

- **메뉴가 보이면 권한이 있는 것이다.** 「담당자 명단에 없는데 관리 화면이 열린다」는 오탐이 되기 쉽다 —
  게이트가 **메뉴 단위 권한**이고 담당자 명단과 별개인 제품이 흔하다. 권한이 코드가 아니라
  관리 화면에서 부여되는 구조인지 먼저 확인한다.
- **「관리자인데 권한 없음」은 대개 계정 레코드가 중복된 경우다.** 화면에 뜬 이름이 아니라
  **토큰의 사용자 id** 를 명단 API 와 대조한다.
- 권한 없는 조작이 **행·라디오는 선택되는데 실행 버튼이 `disabled`** 라면 정상 구현이다 —
  「선택된다」만 보고 결함으로 올리지 않는다.

## D. 로케일 계열

- **계정 언어가 다르게 설정된 계정은 화면이 그 언어로 나온다.** 결함이 아니다. 설정 파일의 언어 칸을 먼저 본다.
- **지원 로케일이 코드에서 클램프되는 제품이 있다.** 지원 대상 밖 언어의 번역 결손은 오탐 —
  파리티 대상 로케일 목록을 먼저 확인한다.
- 반대로 **프레임워크 기본 영문 에러 화면**이 사용자에게 노출되는 것은 결함이다.

## E. 서버 응답을 프론트 문구로 오인

화면에 뜬 문구가 **서버가 준 거절 사유**일 수 있다. 프론트 코드에 그 문자열이 없으면 서버발이다.

```bash
git -C <레포> grep -n "화면에 뜬 문구" <remote>/<기준브랜치> -- <앱 경로>
```

프로덕션 코드에 없고 `*.test.*` 에만 있으면 → 서버 응답이다. 테스트 픽스처에만 있는 문자열을
프론트 구현으로 착각하지 않는다. 그리고 **환경 설정 문제일 수 있다** —
예: 허용 목록이 0건이라 그 경로로는 통과가 애초에 불가능한 상태.

## F. 명세가 틀린 경우

코드·실화면이 명세와 다를 때 **항상 코드가 틀린 것은 아니다.** 명세 작성 이후 기획이 바뀌었고
명세가 안 따라온 경우가 있다. 확정된 티켓(완료)이 현재 동작을 요구했다면 → **명세 보완**이 답이고
그 항목은 오탐이다.

판별법 — 그 동작을 요구한 티켓이 완료 상태로 있는지 찾는다. 있으면 명세 쪽을 고친다.

## G. 한 화면에서 본 것을 전역으로 확대하지 않기

「빈 상태 문구가 두 번 렌더된다」류는 화면마다 다르다. **음성 대조군**(정상인 다른 화면)을 찾아
범위를 좁혀 적는다.

## H. 판정 전 마지막 자문 3개

1. 이 근거는 **워킹트리가 아니라 배포 기준 브랜치**에서 나왔는가
2. 「기획의도라서 오탐」이라면 **조항 번호나 티켓번호**를 댈 수 있는가 — 못 대면 「기획확인」이다
3. 이 항목이 과거 QA 에서 **이미 오탐으로 확정**된 것은 아닌가 (재조사 금지 목록 확인)
