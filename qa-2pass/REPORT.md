# 산출물 포맷

## 1차 — `pass1-raw-<날짜>.md` (스크래치패드)

머리말에 스윕 조건을 남긴다. 나중에 범위를 되짚을 근거다.

```markdown
# 1차 블라인드 QA — <기능> / <탭> · <날짜>
- 테스트 서버 빌드 시점: <확인한 값 또는 "미확인">
- 계정: <등급별 목록>
- 훑은 화면: 목록 / 등록 모달 / 상세 / 삭제
- 표시 매트릭스: 1280×800 펼침 · 1920×1080 · 360×740 · ko/ja · 최악 데이터(가장 긴 조직명 「…」, 열 31개) — 안 돈 칸: <이유>
- 안 본 것: <이유와 함께>
```

항목은 하나씩 **원인 칸 없이** 적는다.

```markdown
## P1-07
| | |
|---|---|
| 축 | ④ 기능 완성도 |
| 화면 | <기능> > <탭> |
| 계정 | 일부 권한 계정 |
| 조작 | 시작 18:00 / 종료 09:00 입력 후 저장 |
| 관찰 | 저장됨. 리로드 후 유지. 경고 0건 (옵저버 확인, 같은 세션 다른 토스트는 포착됨) |
| 재현 | 3회 중 3회 |
| 스크린샷 | shot-p1-07.png |
| 사용자 영향 | 잘못된 기록이 남고 화면에서 지울 수단이 안 보인다 |
```

축 ⑤ 항목은 측정 수치와 재현 조건을 칸으로 둔다.


### 화면 예시가 있는 판정서 — 페이지별 HTML

화면 예시(목업)가 하나라도 있으면 위 마크다운 대신 `verdict-template.html` 을 복사해 HTML 로 낸다.
요약 · 기획확인은 위와 같고, 결함 본문은 **A/B 묶음별이 아니라 페이지별 절**로 묶는다 — 한 페이지의 항목 표(묶음 태그 포함) 바로 아래에
그 페이지 목업을 둔다. 항목 표에는 「화면 예시」 칸을 두고 `M<번호>` 또는 불필요 사유(「불필요(문구)」)를 적는다.
무엇을 언제 그리는지는 `MOCKUP.md`.

## 재시험 판정서 — `retest-<날짜>.html`

`verdict-template.html` 뼈대를 쓰되, 페이지별 절 대신 **티켓별 절**로 묶는다.

- **머리**: 자리([A] · [B] · [C]) · 시험한 빌드(프론트 커밋 · 배포 시각) · 대상 주소 · 계정 · 매트릭스 · 데이터 조작 · **트래커 대체로 돈 동작**
- **요약 표**: 티켓 | 판정(FAIL · BLOCKED · INCONCLUSIVE · PASS) | 기준 수(PASS/FAIL/BLOCKED/INCONCLUSIVE/N/A) | 댓글 초안 위치
- **티켓별 절**:
  - 판정 배지 + 이유 한 줄
  - 기준표: ID | 출처 | 판정 | 증거 한 줄(측정값 · 「스크린샷 확인: …」) — C 와 X 를 나눠서
  - FAIL 기준: 기대 / 실제 / 재현 횟수 / 4단계 확인(재현 · 반영 · 계정 · 데이터) 결과 · 화면을 봐야 이해되면 목업(`MOCKUP.md`)
  - BLOCKED · INCONCLUSIVE: 이유와 「무엇이 있으면 잴 수 있나」
  - 범위 밖으로 둔 것(티켓이 뺀 것) · 범위 밖 발견(이번에 본 것 — 1차 후보 형식)
- **끝**: 실기기 확인 목록 · 안 본 것(확장 상한으로 잘린 것) · 테스트 서버 잔여 · RESULT 블록(`RETEST.md` 7)

채팅 보고도 같은 순서: 티켓별 판정 한 줄 → FAIL · BLOCKED 이유 → 댓글 초안을 게시할지 질문.

## 「판단 못 함」은 남기지 않는다

결함·오탐·기획확인 셋 중 하나로 못 떨어뜨린 항목이 있으면 **판정서를 내지 않는다.**
근거가 부족하면 그건 「기획확인」이고, 측정이 부족하면 재측정한다.

결함 · 기획확인 항목에 **명세 대비(A / B1~B5) 표시가 빠진 것**이 있어도 판정서를 내지 않는다.
A 인지 애매하면 B 다 — A 는 조항 문언 인용과 층 대조가 모두 있을 때만 쓴다.

## 사용자에게 보고할 때

채팅 보고도 판정서와 같은 순서로 두 묶음을 나눈다.

1. **명세상 명확한 결함(A) N건** — 한 줄씩, 조항 번호와 함께
2. **명세로는 확정되지 않는 것(B) N건** — 유형(B1~B5)별로 묶어 한 줄씩, 왜 A 가 아닌지 짧게
3. 오탐 N건은 건수와 대표 근거만
